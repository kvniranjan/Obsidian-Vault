# Budibase - Open-Source Low-Code Platform for Internal Tools and AI Workflows

## What is it?
Budibase is an open-source, low-code platform that enables teams to build internal tools, admin panels, dashboards, and automated workflows without heavy development effort. With a drag-and-drop UI builder, multi-source data connectors, and built-in workflow automation, it lets business analysts and developers rapidly deliver operational applications. Over 200,000 teams rely on Budibase, and it is self-hostable under the GPLv3 license with unlimited users for free.

## Why it matters for Business Analysts
BAs frequently bridge the gap between business requirements and working solutions, and Budibase lets them prototype and even deploy production-grade tools directly—without waiting on development queues. Approval workflows, data entry forms, reporting dashboards, and stakeholder portals can all be built and iterated quickly from gathered requirements. The platform's AI agent layer (Budibase 3.0+) enables automating repetitive BA tasks such as data extraction, status updates, and routing decisions. Because it connects to virtually any data source (PostgreSQL, REST APIs, Google Sheets, etc.), BAs can surface and validate data from existing enterprise systems during requirements discovery and stakeholder demos.

## How to use it in BA Workflows
1. **Rapid Prototyping of Requirements** - Build clickable, data-connected prototypes directly from user stories and wireframes, enabling stakeholders to validate requirements against a working interface rather than a static document.
2. **Approval and Review Workflow Automation** - Configure multi-step approval workflows (e.g., change requests, business case sign-offs) with role-based access, notifications via Slack/email, and audit trails—eliminating manual email chains.
3. **Stakeholder Data Portals** - Create self-service portals that allow business stakeholders to view, filter, and update data relevant to their domain without needing developer-built reports.
4. **Process Metrics Dashboards** - Connect to operational databases and APIs to build live dashboards that track KPIs and process health, supporting continuous monitoring activities after go-live.
5. **AI-Assisted Operations** - Use Budibase's AI agents to automate data aggregation, categorise incoming requests, and trigger downstream actions—reducing manual BA effort in recurring analytical cycles.

## Key Features
- **Drag-and-drop UI builder** - Assemble forms, tables, charts, and custom components visually without writing frontend code
- **Multi-source data connectors** - Native connections to PostgreSQL, MySQL, REST APIs, Google Sheets, S3, Airtable, and more
- **Built-in automation engine** - Trigger workflows via cron, webhooks, or data events; integrate with Slack, email, and external APIs
- **AI agents (Budibase 3.0+)** - Model-agnostic AI layer for automating operational tasks and enriching data pipelines
- **Role-based access control** - Fine-grained permissions ensure stakeholders only access data relevant to their role
- **Self-hosting under GPLv3** - Full control over data and infrastructure; unlimited users at no cost when self-hosted

## Technology Stack
- **Languages:** TypeScript, JavaScript, Svelte
- **Dependencies:** Node.js, CouchDB (internal metadata), supports PostgreSQL, MySQL, and many external DBs as data sources
- **License:** GPL-3.0 (self-hosted free forever; cloud plans available)
