# ToolJet - AI-Native Low-Code Platform for Internal Tools and Business Workflows

## What is it?
ToolJet is an open-source, AI-native low-code platform for building internal tools, admin dashboards, business applications, and workflow automations. It provides a drag-and-drop visual builder that connects to 80+ data sources including databases, REST APIs, SaaS apps, and cloud storage. With ToolJet 3.0, it has evolved into a full enterprise-grade platform capable of running AI agents alongside traditional workflow automation.

## Why it matters for Business Analysts
BAs frequently need to prototype, validate, and demonstrate process solutions without waiting for development teams to build full applications. ToolJet allows BAs to build functional CRUD interfaces, KPI dashboards, and data management tools directly from requirements — turning wireframes into working prototypes stakeholders can interact with. Its workflow engine lets BAs model and automate multi-step business processes visually, closely aligned with how they already think in flowcharts and process maps. The 80+ integrations mean BAs can wire up real business data from existing systems (CRMs, databases, spreadsheets), making demos and proof-of-concepts far more convincing during stakeholder reviews.

## How to use it in BA Workflows
1. **Rapid Prototype Dashboards** - Build a working KPI dashboard with real data in hours, not weeks. Connect to an existing database or spreadsheet, drag in charts and tables, and share the link with stakeholders for immediate feedback rather than waiting on developer capacity.
2. **Data Validation and Cleansing Interfaces** - Create a simple CRUD admin panel over a data source to let SMEs review, correct, and validate data records during a business analysis engagement — especially useful for data migration and data quality projects.
3. **Process Automation for Approval Workflows** - Use the Workflows builder to implement multi-step approval processes (e.g. expense approvals, request intake forms, change request routing) and demo them to stakeholders before formal system development begins.
4. **Requirements Elicitation through Functional Mockups** - Replace static wireframe documents with interactive ToolJet apps. Stakeholders can click through real forms and see live data, surfacing requirements gaps that flat mockups never reveal.
5. **Operational Reporting for Business Teams** - Deploy self-serve reporting tools for business teams (sales, ops, finance) that pull from existing data sources — reducing ad-hoc report requests to the BA/IT team and freeing time for higher-value analysis work.

## Key Features
- **Visual App Builder** - Drag-and-drop UI with 100+ pre-built components (tables, forms, charts, maps, kanban boards)
- **Workflows Engine** - Visual workflow designer for multi-step automations with branching, loops, and conditional logic
- **AI Agent Support** - Embed AI agents into apps and workflows for LLM-powered automation steps
- **80+ Data Source Integrations** - Connects to PostgreSQL, MySQL, MongoDB, REST APIs, GraphQL, Google Sheets, Airtable, Stripe, Salesforce, and more
- **Role-Based Access Control** - Fine-grained permissions to control who can view, edit, or use specific apps
- **Self-Hosted or Cloud** - Can be deployed on-premises for data-sensitive organisations using Docker or Kubernetes

## Technology Stack
- **Languages:** TypeScript, JavaScript
- **Frontend:** React
- **Backend:** Node.js
- **Dependencies:** PostgreSQL (metadata store), Docker/Kubernetes for deployment
- **License:** AGPLv3 (Community Edition); commercial Enterprise Edition available
