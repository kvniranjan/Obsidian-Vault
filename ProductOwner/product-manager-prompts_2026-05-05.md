## What It Is
This is a curated prompt and prompt-generator repository for product management work. The core folders include `/prompts/` for execution-ready artifacts, `/prompt-generators/` for building or adapting prompts, `/storytelling/` for communication assets, `/skeletons/` for prompt analysis, and `/vibes/` for experimental agentic workflows. It is a template and workflow library, not a SaaS app.

## Why It Is Useful For Product Owners
For backlog refinement, it includes prompts for user stories and epic hypotheses. For discovery, it includes Jobs-to-be-Done, proto-persona, customer journey, and research-oriented templates. For stakeholder alignment, it includes positioning, storytelling, product FAQ, and press-release-style framing. For delivery coordination, it helps turn vague stakeholder input into clearer assumptions, candidate stories, acceptance criteria, and follow-up options.

## How I Would Actually Use It
1. Use [user-story-prompt-template.md](https://github.com/deanpeters/product-manager-prompts/blob/main/prompts/user-story-prompt-template.md) before refinement to turn a rough feature request into better stories and acceptance criteria.
2. Use [backlog-epic-hypothesis.md](https://github.com/deanpeters/product-manager-prompts/blob/main/prompts/backlog-epic-hypothesis.md) when an epic is really an untested assumption pretending to be a delivery plan.
3. Use [jobs-to-be-done.md](https://github.com/deanpeters/product-manager-prompts/blob/main/prompts/jobs-to-be-done.md) before prioritization so the team debates customer progress, not stakeholder volume.
4. Use [positioning-statement.md](https://github.com/deanpeters/product-manager-prompts/blob/main/prompts/positioning-statement.md) when sales, leadership, and delivery are describing the product in three different ways.
5. Use [a-generative-AI-prompt-builder-for-product-professionals.md](https://github.com/deanpeters/product-manager-prompts/blob/main/prompt-generators/a-generative-AI-prompt-builder-for-product-professionals.md) to create team-specific prompts for recurring workflows.
6. Use [persona-first-decision-facilitation-loop.md](https://github.com/deanpeters/product-manager-prompts/blob/main/prompt-generators/persona-first-decision-facilitation-loop.md) when context is incomplete and the PO needs a structured way to move from ambiguity to options.

## Limitations / Watch Outs
The repo assumes the PO is already willing to work with AI assistants. If the team does not use ChatGPT, Claude, Gemini, Copilot, or similar tools, the value drops fast. Some prompts will still require product judgment, evidence, and cleanup before they are safe to put in Jira, Azure DevOps, or a stakeholder deck. The repository is broad, so a PO should start with one workflow instead of trying to operationalize the whole thing.
