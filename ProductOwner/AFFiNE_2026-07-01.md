# AFFiNE

## Verdict
AFFiNE is worth a product owner's time if the team needs one workspace for messy discovery notes, structured planning, whiteboards, and lightweight databases. It is not a dedicated product management system, so do not expect Jira replacement depth, release governance, or portfolio reporting. The value is in reducing context sprawl between docs, canvases, and planning tables.

## What It Is
AFFiNE is an open-source workspace application that mixes a Notion-like document model with a Miro-like canvas. The repository contains the main app, desktop related code, backend packages, docs, build instructions, and release assets. It is a tool, not just a template library or curated list.

## Why It Is Useful For Product Owners
AFFiNE can help a PO capture discovery notes, organize stakeholder inputs, map problem spaces, and turn raw observations into backlog candidates. The whiteboard and document mix is useful for story mapping, opportunity mapping, journey sketches, and lightweight prioritization. The table views and linked pages are useful for maintaining feature ideas, assumptions, open questions, acceptance criteria drafts, and decision records without splitting the work across five tools.

## How I Would Actually Use It
1. Create a workspace per product area with pages for goals, users, metrics, competitors, risks, and current bets.
2. Use the edgeless canvas to map a customer journey, then link each pain point to a page with evidence, screenshots, and candidate stories.
3. Maintain a feature idea table with columns for customer segment, problem, evidence strength, effort guess, expected outcome, and decision.
4. Draft PRDs in pages and embed linked acceptance criteria, open questions, and release notes next to the actual discovery material.
5. Run stakeholder workshops on a shared canvas, then convert the strongest themes into a prioritized delivery table.
6. Keep a lightweight decision log so roadmap changes do not disappear into Slack or meeting notes.

## Limitations / Watch Outs
AFFiNE is not a full backlog tracker. If your team needs sprint boards, issue workflows, dependency tracking, release burndown, or deep Jira integration, this will not replace that. The repo is large, the issue count is high, and self-hosting is still a real technical task. The license is also not a clean one-line MIT answer because GitHub reports `NOASSERTION` and the repository license text has backend related carve-outs.
